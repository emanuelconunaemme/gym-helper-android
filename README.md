# GymHelper (Android)

Initial Android skeleton for GymHelper.

This repository currently includes:
- A single Android `app` module.
- Launcher activity and placeholder home screen.
- Project build configuration (Gradle + Kotlin + Android plugin).
- Starter unit and instrumentation test classes.

No workout features are implemented yet.

## Planned features (not implemented yet)
- Count workout series.
- Trigger rest timeout.
- Track missing sets and exercises.
- Track current workout week in the program.
